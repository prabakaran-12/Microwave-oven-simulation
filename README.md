# Microwave Oven Simulation – Embedded Systems

This project was developed as part of my embedded systems internship.
It simulates the working of a microwave oven using a microcontroller.

Features:
- Keypad based input
- CLCD display
- Timer based operation
- Interrupt handling
- Modular Embedded C code

Tools Used:
- Embedded C
- MPLAB X IDE
- PICSimLab
- PIC Microcontroller
